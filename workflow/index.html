How ORCHID is built

From open thermodynamic databases, papers read from lawful copies and pinned first-principles data, to values that each carry their source, the state they describe and the kind of evidence they are.

A CALPHAD database describes the Gibbs energy of every phase of a chemical system. Behind each database stand papers: an assessment that fitted the model, and the measurements that assessment used. ORCHID collects the open databases and reads the evidence behind them, so that a phase-equilibrium temperature, a formation enthalpy or a phase boundary can be found, compared and reused, together with the exact sentence or table row it came from.

The work runs in eight stages. Machines do the reading, but nothing a machine reads is accepted on trust: every value must be quoted, the quote must be found on the page, and fixed rules decide units, signs and the kind of evidence. The papers themselves are never redistributed.

Each card below links to the code on GitHub and to a short technical note. The full map, with a table of commands, inputs and outputs, is WORKFLOW.md.

The stages

1Sources

What goes in, and under which licence. Openly licensed CALPHAD databases (the SGTE collection of 2,774 binary assessments is the backbone), the published papers those assessments cite, read only from copies the user is entitled to, and pinned snapshots of the Materials Project and OQMD.

Code: catalog.json · import_sgte.py · fetch_mp_hull_snapshot.py · stage notes

2Locate

Each PDF is inventoried once: every table, figure, caption and reference list with its position on the page, and whether it is born-digital or scanned. Every table is then sent to exactly one reading route, or skipped with a stated reason.

Code: inventory.py · routing.py · table_routing.py · stage notes

3Read

Deterministic extractors first: table finders, the vector objects of born-digital figures, calibrated tracing of scanned diagrams. Machine readers then read tables and sentences, and must copy the sentence or table row that prints each value. Two independent readers must agree; a judge settles what they do not, and the rest goes to people.

Code: extraction.py · vector_manifest.py · consensus.py · stage notes

4Gates

Rules any reading must pass: the quote is found word for word on its page and contains the number; every field (phase, method, citation, temperature) is printed in that quote or right next to it; units become K, mole fraction and kJ per mole of atoms only when the basis is printed; lost minus signs are checked on the page image.

Code: quote_fixup.py · flash_window.py · state_requirements.py · stage notes

5Evidence classes

Every value is experimental, model (tied to the exact database file by checksum), DFT, or unspecified; expert-drawn handbook diagrams are a class of their own. Classes are never mixed or averaged.

Code: origin_rules.py · model_evidence.py · assessed-phase-diagrams/ · stage notes

6Derived products

Binary phase diagrams calculated with pycalphad from every SGTE file, convex hulls from DFT and CALPHAD, and the comparison of literature formation enthalpies with DFT, all from pinned inputs.

Code: compute_binary_diagrams.py · build_binary_hulls.py · dft_check.py · stage notes

7Releases

Versioned files (JSON, CSV, Parquet), plain pages per system and compound, an MCP server for AI assistants, and Zenodo records with DOIs.

Code: export_literature_data.py · build_parquet.py · orchid-mcp · stage notes

8Validation

A benchmark of synthetic papers with exact answers, a cross-check against the Kim et al. (2017) compilation of measured formation enthalpies, the DFT comparison, and a hand-checked sample of released values (in progress).

Code: orchid-bench · kim2017_crosscheck.py · build_precision_sample.py · stage notes

Try it in a few seconds

The synthetic demo runs the deterministic extractors on two synthetic papers (generated from open SGTE databases, CC BY 4.0), turns the readings into ORCHID records, checks them and scores them against exact answers. It needs no papers, no API keys and no network.

git clone https://github.com/orchid-calphad/orchid-pipeline
cd orchid-pipeline
pip install -e '.[pdf,demo]'
python examples/synthetic-demo/run_demo.py --out demo-out

It prints a score table and writes demo-out/report.html. Step by step: notebooks/synthetic_demo.ipynb. Install options and how to run the tools on your own papers: the quickstart.

Benchmark, server, data and paper

Benchmark

Twenty synthetic papers with exact truth keys, each rendered born-digital, as a clean scan, a degraded scan and an image-only PDF, with the scorer and baselines.

github.com/orchid-calphad/orchid-bench (publication pending)

MCP server

Lets AI assistants query ORCHID data: systems, compounds, literature values with their quotes, phase diagrams and hulls.

github.com/orchid-calphad/orchid-mcp

Datasets

Release v2026.10: literature values, calculated phase diagrams, hulls, the DFT-vs-experiment benchmark, the phase registry, assessed phase assemblages, 6,043 ESPEI datasets and a bibliography of 9,568 papers, as JSON, CSV and Parquet.

How to cite

If you use ORCHID data, cite the dataset you used, the umbrella record, and the original sources of the data. Release v2026.10 (Version 1) is archived on Zenodo as eight datasets, each with its own DOI.

  • R. Arróyave, J. Saal, D. Shin, ORCHID literature values (version 2026.10; Version 1, machine-extracted), Zenodo (2026). doi:10.5281/zenodo.PENDING-literature
  • R. Arróyave, J. Saal, D. Shin, ORCHID calculated binary phase diagrams (version 2026.10), Zenodo (2026). doi:10.5281/zenodo.PENDING-phase-diagrams
  • R. Arróyave, J. Saal, D. Shin, ORCHID binary convex hulls (Materials Project, OQMD, assessed CALPHAD) (version 2026.10), Zenodo (2026). doi:10.5281/zenodo.PENDING-hulls
  • R. Arróyave, J. Saal, D. Shin, ORCHID DFT-vs-experiment formation-enthalpy benchmark (version 2026.10; Version 1, machine-extracted), Zenodo (2026). doi:10.5281/zenodo.PENDING-dft-benchmark
  • R. Arróyave, J. Saal, D. Shin, ORCHID phase registry (binary systems) (version 2026.10; Version 1, machine-extracted), Zenodo (2026). doi:10.5281/zenodo.PENDING-phase-registry
  • R. Arróyave, J. Saal, D. Shin, ORCHID assessed phase assemblages (binary systems) (version 2026.10; Version 1, machine-extracted), Zenodo (2026). doi:10.5281/zenodo.PENDING-assessed-phase-assemblages
