Open Repository for CALPHAD Hypotheses, Intelligence, and Discovery

ORCHID gathers openly available thermodynamic databases and the evidence behind them — assessed phase diagrams, invariant reactions, thermochemical measurements and first-principles energies — in one place, with the licence, source and evidence class of every value recorded. The data are versioned, citable and machine-readable, built to be used by people and by AI models alike.

Releases

v2026.10 (Version 1, machine-extracted) is archived on Zenodo as eight citable datasets, each with its own DOI, linked by the umbrella record ORCHID data. Every value keeps its evidence class — experimental, model (linked to the exact TDB file by SHA-256), DFT or unspecified — and these are never mixed.

Release notes and known issues. What changed in each release is in the changelog; known issues and limits of Version 1 are listed in the dataset card (known limitations) and in each Zenodo record. Flags such as accepted and ESPEI-ready record screening results, not certification. Report an error: Contribute.

ORCHID-Values: literature values Version 1

Invariant reactions, transitions, phase compositions, thermochemical and structural values read from published papers, with quote and page. doi:10.5281/zenodo.PENDING-literature

ORCHID-Diagrams: calculated phase diagrams Version 1

pycalphad calculations from the SGTE binary collection, each tied to its TDB file by SHA-256. doi:10.5281/zenodo.PENDING-phase-diagrams

ORCHID-Hulls: binary convex hulls Version 1

Materials Project, OQMD and assessed CALPHAD (SGTE) hulls as interval documents. doi:10.5281/zenodo.PENDING-hulls

ORCHID-Parity: DFT vs experiment Version 1

Literature formation enthalpies against Materials Project and OQMD, with a Kim et al. 2017 cross-check. doi:10.5281/zenodo.PENDING-dft-benchmark

ORCHID-Registry: phase registry Version 0

Every phase of each binary system: its names across databases, papers and DFT, models, stability and references; crystal structure only when the stored evidence supports an assignment under the stated tier rules. browse · doi:10.5281/zenodo.PENDING-phase-registry

ORCHID-Assemblages: assessed phase assemblages Version 1

23,129 points deep inside the named phase fields of 2,178 expert-drawn binary diagrams from Okamoto's Desk Handbook, citing the original evaluations; ESPEI ZPF datasets. Data only; no page images. doi:10.5281/zenodo.PENDING-assessed-phase-assemblages

ORCHID ESPEI datasets Version 1

8,591 ESPEI datasets: 6,454 from the literature values and DFT, one folder per evidence class, every value with its source DOI, uncertainty and weight, plus 2,137 optional, tagged phase-constraint datasets. files · doi:10.5281/zenodo.PENDING-espei

ORCHID-Bibliography Version 1

9,570 papers ORCHID knows: what was read, cited, assessed or discovered, with evidence counts and typed relations. browse · doi:10.5281/zenodo.PENDING-bibliography
