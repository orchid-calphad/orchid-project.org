About ORCHID

Open Repository for CALPHAD Hypotheses, Intelligence, and Discovery

Mission

ORCHID is an open, provenance-tracked collection of CALPHAD data: thermodynamic databases (TDB files) and the evidence behind them. Every value records where it came from, under which licence it may be used, and what kind of evidence it is (experimental, model, first-principles or assessed phase diagram). Evidence classes are kept apart and never averaged. The data are versioned, citable and machine-readable, for people and for AI models alike.

What is in it

Database catalog

Openly available CALPHAD databases with elements, phases, source and licence; the redistributable files for download.

Literature dataset

Invariant reactions, transitions, phase compositions, thermochemical and structural values from published papers, each with its source and the quote or table row behind it.

Data explorer

Search the literature values by element, system, compound, DOI or author.

Phase diagrams

Binary phase diagrams calculated from open TDB files, each linked to the exact file and checksum.

DFT vs experiment

Literature formation enthalpies against Materials Project and OQMD, side by side, never averaged.

Hulls & mixing

DFT and CALPHAD formation-energy hulls and mixing curves on one composition axis.

How it is built

  • Readers constrained to quote. Values are read from lawfully held papers by independent machine readers, and each value must come with the verbatim sentence or table row that states it.
  • Quote verification. A value is kept only if its quote is found verbatim on one page of the paper and the printed number is inside it; tables are accepted only when independent readers agree.
  • Field placement. Every published field (phase, method, reaction, citation, temperature) must be printed in the value's own quote or its immediate context; fields that are not are removed.
  • Printed-page sign checks. Minus signs lost by the PDF text layer are checked on the rendered page; values printed without a sign are kept as printed and flagged.
  • DFT comparison. Formation enthalpies are paired with the lowest-energy Materials Project and OQMD entries at the same composition, as an independent plausibility check.

Details, counts and the field reference are on the dataset page; every stage, with links to its code, is on How ORCHID is built.

Licensing

  • Derived data (values, units, conditions, phases, compositions, evidence classes, citations): CC BY 4.0. Credit ORCHID and the original paper of each value.
  • Quotes. Each quote is a short excerpt kept only so that a value can be checked against its source; it remains under the publisher’s copyright and is not relicensed.
  • Papers are not redistributed. No PDFs, page images, crops or full text; read the papers at the publisher through the DOI.
  • Third-party databases and data keep their own licences, listed in NOTICE and LICENSES. Files we may not redistribute are listed with links to their sources only.
  • Site code and catalog: MIT.

Contributing

Found a wrong value, or know a paper we should read? Every value on the data pages has a report link that opens a pre-filled GitHub issue; papers and assessments can be suggested with an issue form, and data are contributed by pull request. Every contribution is checked against its source and credited. See Contribute to ORCHID.

Software and data citations

These credits describe the ORCHID project and its examples. Cite the papers and software used in your analysis, together with the ORCHID release and original source of each observation. The list does not imply that every dataset was generated with every package. Preserve the versions and commit hashes recorded by each example; a repository link is not a reproducibility pin. Materials Project and OQMD energies retain separate references.

  • pycalphad: Thermodynamic calculations and phase equilibria. R. Otis and Z.-K. Liu (2017), pycalphad: CALPHAD-based Computational Thermodynamics in Python (10.5334/jors.140). Repository.
  • ESPEI: Thermodynamic parameter fitting and uncertainty quantification. B. Bocklund et al. (2019), ESPEI for efficient thermodynamic database development, modification, and uncertainty quantification: application to Cu–Mg (10.1557/mrc.2019.59). Repository.
  • PhaseForge: MLIP-informed CALPHAD construction in the examples. S. Zhu, D. Sarıtürk, and R. Arróyave (2025), Machine learning potentials for alloys: a detailed workflow to predict phase diagrams and benchmark accuracy (10.1038/s41524-025-01814-z). Repository; archived software.
  • PhaseForge+: Construction and experimental tuning of CALPHAD models in the examples; repository name PhaseForgePlus. C. Kunselman, S. Zhu, D. Sarıtürk, and R. Arróyave (2025), Construction and Tuning of CALPHAD Models Using Machine-Learned Interatomic Potentials and Experimental Data: A Case Study of the Pt–W System (10.1007/s11669-025-01222-2). Repository; archived software.
  • Materials Project: DFT structures and energies; repository link is the API client, not the database itself. A. Jain et al. (2013), Commentary: The Materials Project: A materials genome approach to accelerating materials innovation (10.1063/1.4812323). Repository; data resource.
