Phase registry

One entry per phase of each binary system: every name it goes by (CALPHAD databases, papers, Materials Project and OQMD), the models that describe it, where the calculated diagrams make it stable, and example references. A crystal structure is shown when it is certain: from a standard phase name (tier A) or from a unique, agreeing Materials Project + OQMD ground state (tier B, "DFT-supported"); or when the assessment's own crystallographic table states exactly one consistent structure (tier C, "assessor-stated"). Everything else is listed with its candidates for review. Each CALPHAD model shows its definition exactly as written in the TDB file.

Structure rule (PI decision): a prototype is assigned only when certain. Tier A: the phase name encodes one structure (e.g. FCC_A1, BCC_B2, L12_FCC, AL3NI_D011, C15_LAVES, SIGMA) and neither the model stoichiometry, the SGTE crystallographic table nor DFT contradicts it. Tier B: a stoichiometric compound whose composition matches exactly one on-hull entry in both Materials Project and OQMD, with the same space group and one structure type for that space group and stoichiometry. Tier C (assessor-stated, approved by the PI): the SGTE crystallographic table (Hallstedt 2025, mmc2; CC BY 4.0) lists exactly one structure for this phase name in this system, tiers A/B do not contradict it, and the TDB model matches the listed compound; phases whose rows disagree stay in review. DFT entries are computed 0 K structures, not the CALPHAD phase itself. Files: registry.json (compact index; full records with TDB definitions and references per system in phases/systems/<SYS>.json), registry.csv, JSON-LD, structure types, review queue, conflicts, schema; static page per system (no JavaScript): phases/pages/.
