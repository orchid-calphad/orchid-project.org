Binary phase diagrams

Calculated from open CALPHAD databases with pycalphad. Each diagram names the exact TDB file it came from, with its checksum, so it can be reproduced. Several published assessments exist for many systems; choose one to compare. Pick a system on the periodic table or from the list.

Pick a first element, then a partner (highlighted) to open a system.
